# MCU roster: comics vs film gap list

**Status:** editorial triage, not research. It is written from general knowledge of the comics and the screen versions. No feats are cited, no numbers are implied, and nothing here changes any rating or game result. It exists so the owner can choose a primary version per character before comics evidence is researched. (Tracking: hybrid model from the Gauntlet / version discussion; see `research/option-c/mcu-version-gap.json` to record choices.)

## How to read it
- **Gap** (0-5) is the rough size of the difference between the version on screen and the main comics version.
- **Direction**: *up* = comics is stronger or broader; *side* = different person or different powers rather than stronger.
- **Suggested primary** is a default rule only: `comics` where gap is 4+ and comics is clearly higher; `hybrid` (film primary, comics evidence tagged and discounted) where gap is 3 and comics is higher; `film` otherwise; `choose` where gap is 3+ but the two versions are really different people or power sets, which is a genuine owner decision.
- Hybrid model: one roster entry per character, a primary version, plus source-tagged evidence from the other version. Comics feats are never silently copied onto a film entry.

## Cautions
- Gap sizes are judgment calls. Treat gap 2 versus 3 as approximate.
- Several entries are screen versions of different people (for example Taskmaster, Makkari, Ajak, Ghost, Silver Surfer). Picking comics there changes who the character is, not only how strong they are.
- A few "no counterpart" calls (Miek, Taserface) are marked to verify.
- Characters who came from other studios' films (X-Men, Fantastic Four, Netflix series) are in the roster as screen versions, so the same triage applies.
