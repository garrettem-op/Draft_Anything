# V2 teleportation classification — owner-approved 2026-11-26

The campaign's broad teleport tag is an eligibility concept, not a combat capability. Keep direct self-teleport, portals and transport of others distinct; the existing challenge permits transport of others (e.g. Heimdall). Add magical-teleport, digital-manifestation and dimensional-transport as specific tags. Do not infer unlimited combat evasion from the broad tag.

- Bellatrix Lestrange: self-teleport / magical-teleport; HBP chapter 2, independent Apparition. Respect anti-Apparition wards.
- Agent Smith (The Matrix, 1999): digital-manifestation, conditional on a compatible connected host and simulated environment. Rogue/viral forms require separate evidence; duplication is not inherently relocation.
- Anti-Monitor: dimensional-transport / teleports-others; Crisis on Infinite Earths #11–12, Earth moved into antimatter universe. No verified free self-blink or combat dodge; owner-approved broad campaign eligibility only.

For Option C combat implementation, use independently verified form-scoped mobility/capabilities. Model mechanism, self versus other target, dimensional/environment/host constraints, equipment, range and activation limitations separately. Do not grant a free reposition, dodge or targeting bypass merely because a campaign tag exists. Existing combat scoring is deliberately unchanged by this eligibility correction.

Acceptance: direct teleporters can reposition only under documented conditions; portal users need their standard portal ability/equipment; host transfer requires compatible hosts; external dimensional transport does not imply self-teleport; speed, astral projection, and replication alone do not qualify. Preserve existing campaign grants pending independent review rather than silently revoking them.
