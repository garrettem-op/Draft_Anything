# Middle-earth attribute review (Version 2, 2026-11-27)

The Middle-earth pool was seeded from archetype templates (`data/new-pool-core.js`): every Maia started with Strength 93 and Size 89, every Elf with a warrior's Strength, Touch and Accuracy, every Man of the West with the same ranger's body. That made Tar-Míriel, a queen with no feat of arms, beat Aragorn 72% of the time, and Gimli lose to Legolas 97% of the time.

This review corrects only the entries where the character clearly contradicts the template, on the same 1–99 scale as the hand-authored Marvel pool (Captain America 84/93/88 with Size 70, Black Widow Size 50, Thor Size 85). Each row lists only the attributes changed. They are editorial ratings of the character as written, backed by the cited source for what the character is; they are not measurements.

Version 1 is not changed. The Valar and Morgoth are left as they are (owner's cosmic rulings of 2026-11-27), and so are the Elf-lords and captains whose template already fits a great warrior.
