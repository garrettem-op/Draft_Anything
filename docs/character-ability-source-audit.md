## Status definitions

| Status | Meaning |
| --- | --- |
| verified | The feat itself was checked against a confirming source (so far: the Disney review in PR #55). |
| owner-ruling | Granted or settled by the owner. |
| official-cited | Cites an official, game-data, dialogue or editorial source. The record was written from that source; this audit did not re-open it. |
| provisional | Community sources only (wikis, Fandom, TV Tropes, Comic Vine). A lead, not confirmed canon. Still granted. |
| unsourced | A reviewed pre-audit carry-over with a description but no source link. Still granted. |
