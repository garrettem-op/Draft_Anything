# Harry Potter attribute review (Version 2, 2026-11-27)

The Harry Potter pool was seeded from archetype templates (`data/new-pool-core.js`): every pet and small creature started from the same beast (Strength 85, Size 88), every ghost with a duellist's hands, every senior wizard with the same body. Hedwig the owl beat Harry Potter 72% of the time, and a twig-sized Bowtruckle fought him even.

This review corrects only the entries where the character clearly contradicts the template, on the same 1–99 scale as the hand-authored Marvel pool (Captain America 84/93/88 with Size 70, Black Widow Size 50, Rocket Raccoon Size 8). Each row lists only the attributes changed. They are editorial ratings of the character as written, backed by the cited source for what the character is; they are not measurements.

Version 1 is not changed. Dumbledore, Voldemort and the other senior duellists keep their template scores: their duelling records support them.
