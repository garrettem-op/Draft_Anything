# Draft Anything — Version 1 baseline

**Release baseline date:** 2026-11-12  
**Scope:** Current playable pre–Option C game, with existing numeric ratings and simulation engines.  
**Live frontend:** https://garrettem-op.github.io/Draft_Anything/  

Version 1 is the **feature-freeze reference point**, not a claim that all characters have been fully researched or every UI/device scenario has been manually verified. Option C has been approved as a design principle in [the governing specification](OPTION_C_CHARACTER_INTELLIGENCE.md), but its new qualitative evaluator is **not** included in Version 1. Version 2 should branch from this baseline.

## Version 1 included

- **Game modes:** Championship/Perfect Season, ten-stage Campaign, Head-to-Head live multiplayer, three-card Dealt Hand, Daily Grid and archive, and current Battle Royale combat.
- **Talent pools:** NBA (134), MCU (143), Cartoons (134 including Claude's 31 Disney additions), Muppets (101), Video Games (118), Pokémon (151), Star Wars (98), DC (104), Middle-earth (115), Harry Potter/Wizarding World (106), Action Movies (100). Current playable base roster index: **1,304** characters; counts refer to the published character-research service's allowlist, not complete audited knowledge coverage.
- **Roster and draft tools:** Selectable All-Star Mashup pools, live Head-to-Head with Dealt Hand option, character/variant information and eligible Variant Surge, coaching and bench/reinforcement roles.
- **Game systems:** Individual attributes and weighted positions, current sidekick/bench chemistry (8% cap), MuppetForce ensemble synergy (22% team-wide cap), ToonForce, shared character powers, combat signature attacks, exceptional/Apex variants, team chemistry, and existing role restrictions.
- **Results:** Individual box-score reporting and simplified after-action breakdown; 50-match researched men's volleyball scoring calibration; Head-to-Head deterministic box-score seeding to align host and guest views.
- **Research data already integrated from Claude:** Ability-audit index and owner rulings, Round 2/3 evidence, ability-source audit, new DC/Middle-earth/Harry Potter lore, Disney character profiles, source-tracked eligibility corrections.

## Baseline and change policy

- Record the exact **`main` commit SHA** at feature freeze, and maintain a separate **`releases/v1.0.0` branch** pointing to it. The frozen branch is the recovery reference for Version 1 while Version 2 work advances separately. A release branch is **not** a Git tag or a formal GitHub Release.
- Only verified critical fixes should be selectively backported to the frozen Version 1 line. Do not mass-merge outdated branches or let Option C prototypes alter the baseline without evaluation.
- CI commands defined by the current repository include the Node test suite and browser smoke check; per-PR Actions also run the after-action and men's-volleyball workflows. Preserve reproducible seeded test outcomes and keep user-facing match reports consistent.
